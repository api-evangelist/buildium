Buildium, part of RealPage, is a cloud property-management platform aimed at small and mid-sized residential, association, and community-association property managers. The platform covers accounting, leasing, applicant and tenant management, rent collection, maintenance, communications, owner and resident portals, and association management. Buildium publishes a Public API used by certified partners and customers for property, lease, tenant, owner, vendor, rental application, financial, and webhook integration with the Buildium platform.

**Areas:** Property Management · Residential · Community Associations · Accounting · PropTech · Small Business

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Buildium: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
